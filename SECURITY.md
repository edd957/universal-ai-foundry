# Security Policy

## Supported Versions

This is an initial public reference project. Security reports should target the latest version on the default branch.

## Reporting a Vulnerability

Please open a private security advisory if hosted on GitHub, or contact the maintainer directly.

Do not include real API keys, private model weights, paid dataset credentials, or personal data in public reports.

## Project Safety Boundary

Universal AI Foundry is for legitimate local AI training and experimentation. It intentionally excludes offensive automation, unauthorized data collection, model abuse workflows, and unsafe content generation guidance.
