# Modalities

## LLM

The `llm-lora` blueprint targets parameter-efficient local fine-tuning. It is intended for instruction datasets in JSONL format and adapter output artifacts.

## Image

The `image-diffusion-lora` blueprint targets text-to-image diffusion LoRA training. It expects an image folder with captions or sidecar metadata.

## Music

The `music-generator` blueprint targets spectrogram or audio-token based local experimentation. It expects licensed audio clips and keeps preprocessing explicit.

## Video

The `video-diffusion-lora` blueprint targets short video adapter experiments. It expects curated clips with clear rights and controlled resource budgets.
